## Explore ApexGPS

ApexGPS is built for hikers who need route planning and navigation tools in one Android application. It combines offline map areas, topographic views, GPS location, waypoints, tracks, and route recording for outdoor trips where a dependable network connection may not be available.

GPX files can be imported and exported, while elevation profiles, a compass, and hiking weather forecasts support trip preparation and navigation. The app offers six map providers, includes backup and restore capabilities, does not require a subscription, and does not provide tracking.

- Store selected map areas for use without an internet connection

## Getting Started

### Set up a hike for offline use

1. Launch ApexGPS on your Android device.
2. Pick an available map provider.
3. Locate the area you intend to explore.
4. Save that map region for offline access.
5. Before departure, check the route, elevation profile, and weather forecast.

### Capture your route

1. Open the navigation or track-recording tools.
2. Allow GPS access when Android asks for it.
3. Begin live recording before setting out.
4. Use the map, compass, and navigation indicators to stay oriented.
5. Save the finished track after completing the hike.

### Import and export GPX

1. Choose GPX import and load a route, track, or collection of waypoints.
2. Inspect the imported information on the map.
3. Apply it to route planning or active navigation.
4. When required, export the resulting track or waypoints in GPX format.

## Frequently Asked Questions

### Which devices can run ApexGPS?

ApexGPS is designed for Android devices.

### Will maps work when I am offline?

Yes. Save the necessary map regions before your trip, and supported map data can then be used without a network connection.

### Can ApexGPS read and create GPX files?

Yes. GPX import and export are available for routes, tracks, and waypoints.

### Does the app track my hike?

Yes. Live GPS recording can create a track as you move along your route.

### Do I need to pay for a subscription?

No subscription is listed as required for ApexGPS.

### Are hiking forecasts available?

Yes. Hiking weather forecasts are included in the app's navigation feature set.

### Where do I change ApexGPS options?

All settings and data-management functions are available inside the Android application. Use the in-app controls to manage maps, navigation, weather, and backup or restore actions.

### Why might an offline map not appear?

Check that the intended region was downloaded before going offline, that enough device storage remains, and that the chosen provider offers coverage for the area you plan to visit.

### How do I preserve my trip information?

Use ApexGPS backup and restore tools to retain supported navigation data and restore it when necessary.
